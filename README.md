## 🏛️ Featured Project

### 👑 TripC — Smart Travel Planner & Expense Manager

A Flutter application designed to help travellers organize their
journeys and manage travel expenses in one place.

**Key features**
- 🧭 Trip and itinerary management
- 💰 Expense tracking and budget monitoring
- 📊 Analytics and expense breakdowns
- ⚖️ Planned-versus-actual expense comparison
- 📍 Places and travel exploration
- 💾 Local data persistence

**Technology:** Flutter · Dart · Material 3 · SharedPreferences · JSON
